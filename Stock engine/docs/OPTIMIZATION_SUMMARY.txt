⏰ THE 4PM-9AM WINDOW OPTIMIZATION

Why This Matters:
─────────────────
The 4pm-9am (IST) window is optimal for stock prediction because:

  • 4:00 PM:  Indian stock market closes (trading stops)
  • 4:00 PM - 9:00 AM:  Peak news period for next trading day
  • 9:00 AM:  Market opens with all overnight news already available
  • This gives traders max information BEFORE market open

How It Works:
─────────────
1. System checks if current time is 4pm-9am (IST)
2. If OUTSIDE window: Shows warning, allows override
3. If INSIDE window: Fetches latest news for all 50 companies
4. News is filtered to only recent articles (last 24 hours)
5. FinBERT analyzes sentiment of collected news
6. Predictions are made based on sentiment scores

Time Window Logic:
──────────────────
12:00 AM - 9:00 AM   ✓ VALID WINDOW - News collection active
9:00 AM - 4:00 PM    ⏸ OUTSIDE WINDOW - System idle
4:00 PM - 12:00 AM   ⏸ OUTSIDE WINDOW - System continues next day

🔍 TROUBLESHOOTING

Problem: "Outside valid news window" warning
Solution: This is expected if running 9am-4pm. Either:
          • Wait until 4pm for next window, or
          • Use interactive menu to override warning

Problem: No news found for many stocks
Solution: This is normal on quiet news days. Try:
          • Running during different time (more breaking news)
          • Checking internet connection
          • Increasing search query variations

Problem: Import errors after installation
Solution: Ensure all packages installed:
          pip install -r requirements.txt --upgrade

Problem: Slow performance
Solution: Use sampling for testing:
          python app.py sample
