1️⃣  FIRST INSTALLATION

   a) Activate your virtual environment:
      market_env\Scripts\activate

   b) Install dependencies:
      pip install -r requirements.txt

2️⃣  RUNNING THE APP

   Option A - Interactive Menu (RECOMMENDED):
   ───────────────────────────────────────────
   python app.py

   This gives you a menu with options:
   1. Full Pipeline (news → sentiment → prices → predictions)
   2. Sentiment analysis only
   3. Quick test (10 companies)
   4. Fetch prices only
   5. Generate predictions
   6. Schedule automatic runs
   7. View status
   8. Exit


   Option B - Command Line (Quick):
   ─────────────────────────────────
   python app.py run        # Full pipeline
   python app.py sample     # Quick test (10 companies)
   python app.py prices    # Only fetch prices
   python app.py schedule  # Automatic scheduling

⏰  IMPORTANT TIME WINDOW

   Valid News Collection Window:
   ✓ 4:00 PM (previous day) → 9:00 AM (current day)
   
   System Status:
   ✓ 12:00 AM - 9:00 AM  → ACTIVE (collect news)
   ⏸ 9:00 AM - 4:00 PM   → IDLE (wait for market)
   ⏸ 4:00 PM - 12:00 AM  → IDLE (evening hours)

   💡 TIP: For best results, run between 4pm-9am IST!

📊 WHAT EACH OUTPUT FILE CONTAINS

   daily_prices.csv
   └─ Stock prices for Nifty 50 companies
      Columns: Symbol, Open, Close, High, Low, Volume, Percent_Change, Direction

   nifty_sentiment_results.csv
   └─ News sentiment analysis results
      Columns: Symbol, Sentiment_Score, Direction, Headline_Count, Timestamp

   prediction_report.csv
   └─ Final predictions vs actual results
      Columns: Symbol, Prediction, Score, Actual, Correct, Change%

🎯 WORKFLOW EXPLANATION

   Step 1: Time Check
   └─ System verifies if current time is 4pm-9am window

   Step 2: Fetch News
   └─ Searches Google News for each Nifty 50 company
   └─ Only fetches news from valid 4pm-9am window

   Step 3: Sentiment Analysis
   └─ Uses FinBERT model to analyze news sentiment
   └─ Scores from -1 (very negative) to +1 (very positive)
   └─ Generates BULLISH (.sentiment > 0.05) or BEARISH predictions

   Step 4: Fetch Prices
   └─ Gets yesterday's opening and closing prices
   └─ Calculates actual UP or DOWN movement

   Step 5: Compare & Report
   └─ Compares prediction vs actual movement
   └─ Calculates accuracy percentage
   └─ Generates detailed CSV report

❓ COMMON QUESTIONS

   Q: Should I run this during market hours (9am-3:30pm)?
   A: You can, but the news window will show as inactive. Results will 
      be more complete if run during 4pm-9am window.

   Q: Can I test with fewer companies first?
   A: Yes! Run "python app.py sample" to test with 10 companies.

   Q: What if I get a "No News Found" message?
   A: This means no significant news with strong sentiment was found.
      This is normal on quiet news days.

   Q: How long does a full run take?
   A: ~3-5 minutes for all 50 companies (depending on internet speed)

   Q: Can I automate this to run daily?
   A: Yes! Run "python app.py schedule" or use Windows Task Scheduler.
