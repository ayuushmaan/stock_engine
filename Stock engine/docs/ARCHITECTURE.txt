5. TIME WINDOW CONCEPT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    Indian Stock Market Timeline (IST - Asia/Kolkata):
    
    ↓ Previous Day
    │
    3:30 PM  Market Close
         │
    ┌────┴─────────────────────────┐
    │                               │
    4:00 PM  NEWS COLLECTION START  │ ← After-market hours
    │        (News breaks)          │
    │        (Research begins)      │
    │        (Analysts comment)     │
    │                               │
    ↓ Next Day                      │
    │                               │
    12:00 AM (Midnight)            │
    │        (Overnight news)       │
    │        (Continued coverage)   │
    │                               │
         └────┬─────────────────────┘
              │ VALID WINDOW
              │ (12 hours of news)
              │
    9:00 AM  MARKET OPENS          │
         │    (Trading starts)      │ ← Traders act on news
         │    (Prediction valid)    │
         │
    ✓ PREDICTION WINDOW ENDS
    
    Why 4pm-9am?
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    • Maximum news availability
    • All overnight developments captured
    • Traders make decisions at market open
    • Predictions can be validated same day
